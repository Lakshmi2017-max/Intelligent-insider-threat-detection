# Intelligent Insider Threat Detection Using Behavioral Digital Fingerprints

## Description
This project detects insider threats by analyzing user behavior and identifying suspicious activities using behavioral digital fingerprints.

## Features
- User Login
- Activity Monitoring
- Threat Detection
- Risk Alerts
- Dashboard

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## How to Run
1. Install Python
2. Install required packages
3. Run:
   python app.py
